BusTicketApp – Mobile Application
Running the Application
Requirements
Node.js (LTS version)
NativeScript CLI
Android Studio (Android Emulator)
Backend server running locally

Setup
Install project dependencies:
npm install

Build Tailwind styles:
npm run build:tailwind

Run
Start the application on Android Emulator:

ns run android

Backend Configuration
The backend must be accessible at:
http://10.0.2.2:8080

This mobile application was developed as part of a university diploma project.
